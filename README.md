# 🛒 AWT Sales Manager — ERP de Gestão Comercial e Estoque

Sistema **Full Stack de gestão comercial** desenvolvido para centralizar operações de vendas, estoque, produtos, clientes e fornecedores em uma única plataforma.

O projeto foi desenvolvido com foco em **organização operacional, acompanhamento de indicadores e gerenciamento eficiente das rotinas comerciais**.

## ⚙️ Como Executar Localmente

1. Clonar o repositório
git clone https://github.com/awaldige/awt-sales-manager.git
2. Entrar no diretório
cd awt-sales-manager
3. Configurar o ambiente PHP

Utilize um servidor local compatível com PHP, como:

XAMPP
WAMP
Laragon
Apache + PHP

4. Configurar o MySQL

Crie um banco de dados MySQL e importe o arquivo SQL disponibilizado no projeto.

Configure as credenciais de acesso ao banco conforme os arquivos de configuração da aplicação.

5. Executar

Inicie o Apache e o MySQL e acesse o projeto pelo endereço configurado no seu ambiente local.

Exemplo:

http://localhost/awt-sales-manager/
