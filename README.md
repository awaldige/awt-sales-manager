# AWT Sales Manager — Sistema de Gestão Comercial

Sistema web de gestão comercial desenvolvido por **AW TECHNOLOGY**, como projeto de demonstração para portfólio.

O AWT Sales Manager reúne recursos para gerenciamento de vendas, compras, produtos, estoque, clientes e fornecedores, com uma interface responsiva e painéis de acompanhamento.

## Demonstração online

**Acesse:** https://awt-sales-manager.onrender.com/

## Funcionalidades

- **Dashboard:** indicadores e acompanhamento das operações comerciais.
- **Vendas e pedidos:** cadastro, gerenciamento e acompanhamento de pedidos.
- **Produtos:** cadastro, edição, categorias e controle de custos e valores.
- **Estoque:** acompanhamento e movimentação de produtos.
- **Compras:** registro de compras, fornecedores e itens das notas.
- **Clientes e fornecedores:** gerenciamento dos cadastros.
- **Formas de pagamento:** configuração e gerenciamento.
- **Usuários:** gerenciamento de contas e níveis de acesso.
- **Documentos:** geração de recibos e documentos em PDF.

## Tecnologias utilizadas

- PHP 8
- MySQL
- HTML5
- Tailwind CSS
- JavaScript
- Git e GitHub

## Segurança e controle de acesso

O sistema conta com autenticação por sessão, validação de dados, consultas preparadas, proteção contra solicitações CSRF e controle de permissões por nível de usuário.

As operações administrativas possuem restrições específicas de acesso.

## Interface

O projeto possui interface responsiva, com páginas de gerenciamento, formulários e painéis desenvolvidos para facilitar a utilização em diferentes tamanhos de tela.

## Objetivo do projeto

O AWT Sales Manager foi desenvolvido como projeto demonstrativo para apresentar conhecimentos em desenvolvimento web, integração com banco de dados, lógica de negócio, controle de acesso e construção de sistemas de gestão.

Este projeto faz parte do portfólio da **AW TECHNOLOGY**.
